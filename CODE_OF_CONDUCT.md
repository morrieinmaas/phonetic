# Code of conduct

Phonetic follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique code and not people, and keep discussion on
topic. Harassment, insults and personal attacks are not tolerated in issues, pull requests or any
other project space.

Report a problem privately to mo [at] traect [dot] dev. Reports are handled confidentially. The
maintainer may edit or remove comments, close threads, and block anyone who breaks these rules.
